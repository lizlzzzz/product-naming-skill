# 中文、英文与双语命名

## 中文

先找真实场景中的短词，再考虑压缩。通常先试 2–4 字，按口播和功能线索取舍。连续读三遍，检查轻重、同音别义、输入法首选词和常见误写。避免用一批“智、灵、云、星”换尾字来凑数量。

## 英文

| 构词路径 | 样本 | 如何尝试 |
|---|---|---|
| 原词借义 | Cursor、Runway | 从用户熟悉的物件和场所找词，检查最常见义项 |
| 复合与功能拼接 | CapCut、Photoshop、ChatGPT | 连接动作与结果，或清晰的类别词与差异词 |
| 抽象借词 | Notion、Linear、Perplexity | 给抽象词配一句产品解释，测试用户能否说回预期意思 |
| 拟声与节奏 | TikTok | 优先朗读，检查节奏能否对应直观拼法 |
| 造词和拼写变体 | Figma、Canva、Spotify | 先定一种自然读法，再调整元辅音排列 |
| 人名与角色 | Claude、Alexa、Copilot | 检查称呼是否自然，以及角色是否误导用户预期 |
| 母品牌和功能词 | TikTok Shop、GitHub Copilot | 保留授权使用的词根，用后半段清楚区分产品 |

用“听一遍能写出来”和“看一眼能读出来”两道检查。检查口语义、俚语、同音词和目标地区的读法。标记基于字面的判断与实际母语者反馈。不要根据名字编造官方词源。

## 双语配对

1. 先确定共用主品牌、音译、意译，或中英文分别命名。若用户有主市场，先满足其传播需求。
2. 分别在两种语言中按产品价值生成并筛选，从过筛候选中配对。没有必要逐字对应。
3. 对每组检查核心联想、口头传播、可识别的品牌关系与跨市场的负面含义。先按较弱一侧判断底线，再看整组一致性。
4. 对照参考案例。剪映 / CapCut 可比较如何保留编辑动作。飞书 / Lark 可比较同类办公定位下不同的语言意象。微信 / WeChat 可比较两地的沟通线索。这些是命名比较，样本的产品实体和运营地区以官方资料为准。
